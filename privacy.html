한눈에 보기

말문은 서버가 없는 앱이에요. 개발자는 이용자의 개인정보를 수집하지 않고, 저장하지 않고, 다른 곳에 제공하지 않아요. 공부 기록과 녹음은 이용자의 기기 안에만 저장돼요.

1. 수집하는 개인정보

없어요. 회원가입, 로그인, 이름·이메일·전화번호 입력, 광고, 방문 분석 도구가 없어요.

2. 기기에 저장되는 정보

아래 정보는 앱을 쓰기 위해 이용자의 브라우저 안에만 저장되고, 개발자를 포함한 누구에게도 전송되지 않아요.

항목저장 위치
공부 진도, 레벨, 설정, 배지브라우저 localStorage
1분 말하기 녹음브라우저 IndexedDB
AI용 API 키 (넣은 경우에만)브라우저 localStorage

3. 외부로 전송되는 경우

아래 기능은 이용자가 직접 켜거나 누를 때만 작동하며, 각 회사의 개인정보 정책을 따라요.

  • 마이크로 말하기(받아쓰기): 브라우저의 음성 인식 기능을 사용해요. 이용하는 브라우저에 따라 음성이 Google(Chrome) 또는 Apple(Safari) 서버로 전송될 수 있어요. 원하지 않으면 키보드 입력이나 녹음 버튼을 쓰세요. 녹음 버튼으로 남긴 소리는 기기 밖으로 나가지 않아요.
  • AI와 대화 (선택): 이용자가 설정에 직접 넣은 API 키와 대화 내용이 Anthropic API로 전송돼요. 키를 넣지 않으면 전송되지 않아요.
  • 외부 링크: 듣기 자료 링크(BBC, VOA, TED-Ed)를 누르면 해당 사이트로 이동해요. 이때 말문 주소는 전달되지 않아요.
  • 호스팅: 앱 파일을 내려받을 때 호스팅 서비스(GitHub Pages)가 일반적인 접속 기록(IP 주소 등)을 남길 수 있어요.

4. 보관 기간과 삭제

기기에 저장된 정보는 이용자가 지울 때까지 남아 있어요. 앱의 기록 › 설정 › 진도와 녹음 모두 지우기를 누르거나, 브라우저의 사이트 데이터를 삭제하면 모두 지워져요. API 키는 설정 › 키 지우기로 따로 지울 수 있어요.

5. 안전을 위한 조치

  • 콘텐츠 보안 정책(CSP)으로 앱 파일과 Anthropic API 외의 연결과 외부 스크립트를 막아요.
  • 백업 파일을 불러올 때 정해진 형식의 값만 받아들이고, API 키는 백업 파일에 넣지 않아요.
  • 글꼴과 아이콘을 앱 안에 넣어 외부 서버에 요청하지 않아요.

6. 만 14세 미만 이용자

말문은 개인정보를 수집하지 않아 별도의 법정대리인 동의 절차가 없어요. 다만 AI 기능의 API 키 발급과 이용은 Anthropic의 이용 조건(연령 제한 포함)을 따라요.
