# 말문 — 매일 20분 영어 말하기

말문이 트일 때까지, 매일 같은 순서로 20분 연습하는 무료 영어 회화 앱입니다.
설치 없이 브라우저에서 열고, 홈 화면에 추가하면 **인터넷 없이도** 작동해요.

## 하루 루틴

1. **표현 카드** — 바로 쓰는 회화 표현 336개 (14개 분야). 한국어를 보고 영어로 말한 뒤 정답 확인. 간격 반복으로 잊어버릴 때쯤 다시 나와요.
2. **바꿔 말하기** — 패턴 30개 × 4문장. `I'm allergic to ___` 같은 틀에 내 상황을 넣어 말하는 연습.
3. **듣기 30분** — 기본 듣기 자료 12개 (글 없이 듣기 → 문제 → 대본 보며 다시 듣기) + 밖에서 들은 시간 기록.
4. **섀도잉** — 대화문 16개. 원음 듣기 → 따라 말하기 → 앱 안에서 녹음해 원음과 비교 → 말해서 채점.
5. **실전** — 앱이 상대 역할을 하는 **역할극**(오프라인), 또는 **AI 대화**(선택).

그 밖에
- **3분 레벨 테스트** — 결과에 맞춰 난이도와 하루 분량을 정해요.
- **1분 말하기 기록** — 한 달에 한 번 같은 질문으로 녹음. 1분당 단어 수와 막힘 정도로 성장을 확인해요.
- **실제 사람과 대화 기록** — 일주일에 두 번이 목표.
- **매일 알림** — 휴대폰 캘린더에 반복 일정으로 추가.
- **백업/불러오기** — 진도를 파일로 옮겨요.

## 인터넷 없이 되는 것 / 안 되는 것

| 기능 | 오프라인 |
| --- | --- |
| 표현 카드, 바꿔 말하기, 듣기 자료, 섀도잉, 역할극, 녹음, 레벨 테스트 | 됨 |
| 읽어 주기 | 기기에 설치된 영어 음성을 써요. 대부분의 휴대폰은 오프라인으로 됨 |
| 받아쓰기(마이크 버튼) | 브라우저에 따라 인터넷이 필요해요. 대신 휴대폰 키보드의 음성 입력을 쓰면 돼요 |
| AI 대화, AI로 새 자료 만들기 | 인터넷 + 본인 API 키 필요 |

## AI 기능 (선택)

기록 › 설정에 본인의 [Anthropic API 키](https://console.anthropic.com/)를 넣으면 켜져요.
키는 그 기기의 브라우저에만 저장되고 Anthropic API로만 전송됩니다. 사용 요금은 키 주인 계정에 청구돼요.
AI로 만든 듣기 자료와 대화문은 저장되어 이후 오프라인에서도 쓸 수 있어요.

## 개인정보와 보안

전체 내용은 [개인정보 처리방침](privacy.html)에 있어요.

- **서버가 없어요.** 말문은 정적 파일만 있는 앱이라 이름, 이메일, 진도, 녹음 등 어떤 정보도 개발자에게 전송되거나 수집되지 않아요. 분석·광고 도구도 없어요.
- **진도와 녹음은 기기에만 저장돼요** (브라우저 localStorage, IndexedDB). 설정 › "진도와 녹음 모두 지우기"로 전부 지울 수 있어요.
- **글꼴과 아이콘도 앱 안에 들어 있어서** 외부 서버(구글 폰트 등)에 요청하지 않아요.
- **마이크 받아쓰기**는 브라우저 기능을 써요. Chrome은 Google, Safari는 Apple 서버로 음성을 보낼 수 있어요. 녹음 버튼으로 남긴 소리는 기기 밖으로 나가지 않아요.
- **AI 기능(선택)**: 넣은 API 키와 대화 내용은 Anthropic API로만 전송돼요. 키는 브라우저에 저장되므로 사용 한도를 낮게 정한 전용 키를 쓰세요. GitHub Pages에서는 같은 계정의 모든 저장소 페이지(`아이디.github.io`)가 저장 공간을 공유하므로, 같은 계정에 믿을 수 없는 코드를 함께 올리지 마세요.
- **보호 장치**: 콘텐츠 보안 정책(CSP)으로 앱 파일과 Anthropic API 외의 연결과 스크립트를 막아요. 백업 파일을 불러올 때는 정해진 형식의 값만 받아들이고, API 키는 백업에 들어가지 않아요. 화면에 보이는 모든 글자는 HTML로 해석되지 않도록 처리해요.

## 한계

- 채점은 **받아 적힌 단어**를 원문과 비교하는 방식이에요. 억양·강세·연음은 평가하지 못하니, 녹음해서 원음과 직접 비교하세요.
- 진도는 각 기기의 브라우저에 저장돼요. 브라우저 데이터를 지우면 사라지니 가끔 백업하세요.

## 직접 실행하기

빌드 과정이 없는 정적 사이트예요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

GitHub Pages: 저장소 Settings › Pages › Branch를 `main` / `(root)`로 지정하면 배포돼요.

## 콘텐츠 추가

- 표현: `phrases.js` — `한국어|영어|메모` 한 줄에 하나
- 패턴: `patterns.js`
- 대화문: `dialogs.js`
- 듣기: `listening.js`

파일을 바꾼 뒤에는 `sw.js`의 `VERSION`을 올려야 설치된 앱에도 반영돼요.
